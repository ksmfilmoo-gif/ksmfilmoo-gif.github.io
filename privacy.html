개인정보처리방침 / Privacy Policy

shorts-comment는 채널 운영자 본인의 유튜브 계정에서만 사용하는 개인용 도구입니다.

  • YouTube Data API로 운영자 본인 채널의 업로드 목록을 읽고, 본인 영상에 정해진 댓글 한 개를 다는 데만 사용합니다.
  • 다른 사용자의 개인정보를 수집·저장·공유하지 않습니다.
  • 인증 정보는 운영자 본인의 GitHub 비공개 저장소 비밀값에만 보관합니다.
  • 권한은 Google 계정 설정(보안 → 제3자 앱 액세스)에서 언제든 해제할 수 있습니다.

This tool only reads the owner's own channel uploads and posts one fixed comment on the owner's own videos via the YouTube Data API. It does not collect, store, or share any other user's data.
